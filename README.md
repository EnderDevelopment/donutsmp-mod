# DonutSMP Mod

Enhance your Minecraft experience with this Fabric mod for 1.21.4

## Features

- **BaseESP**: Highlight player structure terrain passages
- **StorageESP**: Detect and highlight chests, shulkers, and barrels
- **TunnelESP**: Visualize tunnels and passages
- **ChunkFinder**: Locate and highlight new chunks
- **CoordLogger**: Log and display player coordinates
- **WaypointExport**: Export waypoints for easy navigation
- **SpawnerDetect**: Detect and highlight mob spawners
- **ElytraBoost**: Boost elytra flight speed
- **AutoEat**: Automatically eat food when hungry
- **EasyPlace**: Simplify block placement
- **ClusterDetect**: Detect and highlight resource clusters
- **ChestStealer**: Automatically loot chests
- **HiddenDetect**: Detect hidden blocks and entities

## Requirements

- Minecraft 1.21.4
- Fabric Loader
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/donutsmp-mod/releases)
2. Place the mod file in your `mods` folder
3. Launch Minecraft with Fabric Loader

## Usage

1. Launch Minecraft with the mod installed
2. Use the in-game configuration menu to enable/disable features
3. Enjoy the enhanced gameplay experience

## Configuration

The mod includes a configuration file located at `config/donutsmpmod.json`. You can customize the settings for each feature as needed.
